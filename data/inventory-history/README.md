# 在庫推移データ

ストコンの「在庫推移」画面から確認した、中分類単位の時系列データを保存する。

## 取り扱い

- ファイル名は営業日の `YYYY-MM-DD.json` とする。
- `hours` と各中分類の `itemCount` / `stock` は同じ位置が同じ時刻を表す。
- 画面が空欄の値は、数値の `0` と区別するため `null` にする。
- 元写真には店舗名や従業員名が含まれるため、このリポジトリには保存しない。
- 読み取れない数字を推測で補完しない。
- `source.extractionScope` に、JSONへ収録した範囲を記録する。

## 現在の用途

このデータは発注予測の検証用であり、現時点ではアプリの入力値を自動更新しない。
予測への組み込み時は、既存の保存データや発注数を上書きしない確認フローを設ける。
