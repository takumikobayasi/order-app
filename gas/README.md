# GAS設定

`Code.gs` は、現在の発注アプリ同期処理にDrive資料アップロードを追加した版です。

商品名・税込価格・値入率のJSONはGitHubへ置かず、Driveからパス指定で読み取ります。

1. Apps Scriptの既存プロジェクトを開く
2. `Code.gs` の内容をこのファイルで置き換える
3. 保存する
4. 「デプロイ」→「デプロイを管理」→対象のウェブアプリを編集
5. 新バージョンでデプロイする

実行ユーザーは、現在と同じくDriveへ保存できるアカウントにします。アクセスできるユーザー設定も現在のアプリと同じものを維持してください。

## 商品データ読取のアクセスキー

Apps Scriptの「プロジェクトの設定」→「スクリプト プロパティ」に `CATALOG_ACCESS_TOKEN` を追加し、十分に長いランダムな値を設定します。同じ値をアプリの設定画面「Drive商品データ読取」のアクセスキーへ入力してください。キーは端末内だけに保存され、GitHubや同期DBには入りません。

現在の読取パスは `発注アプリ資料/2026-09/構造化データ/商品マスタ_2026-09-04.json` です。読取対象は `発注アプリ資料` 配下のJSONだけに制限しています。

アップロード先は次のように自動作成されます。

現在のアプリからの保存先は、まず次の未仕分けフォルダです。

`マイドライブ / 発注アプリ資料 / YYYY-MM / 未分類`

後で仕分け処理を追加できるよう、GAS側は分類フォルダにも対応しています。

既存の `hacchu_cloud_db.json` は従来どおりマイドライブ直下で使います。
