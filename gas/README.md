# GAS設定

`Code.gs` は、現在の発注アプリ同期処理にDrive資料アップロードを追加した版です。

1. Apps Scriptの既存プロジェクトを開く
2. `Code.gs` の内容をこのファイルで置き換える
3. 保存する
4. 「デプロイ」→「デプロイを管理」→対象のウェブアプリを編集
5. 新バージョンでデプロイする

実行ユーザーは、現在と同じくDriveへ保存できるアカウントにします。アクセスできるユーザー設定も現在のアプリと同じものを維持してください。

アップロード先は次のように自動作成されます。

`マイドライブ / 発注アプリ資料 / YYYY-MM / 分類`

既存の `hacchu_cloud_db.json` は従来どおりマイドライブ直下で使います。
